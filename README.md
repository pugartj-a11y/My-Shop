# MEME BUDDIES — My Shop

Адаптивный демонстрационный сайт бренда коллекционных 3D-брелков.

## Запуск локально
Откройте `index.html` в браузере.

## Публикация через GitHub Pages
1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Выберите ветку `main` и папку `/(root)`, затем Save.
4. После публикации сайт будет доступен по адресу GitHub Pages, который покажет GitHub.

## Возможности прототипа
- Адаптивная главная страница.
- Каталог из шести персонажей.
- Демонстрационные цены в евро.
- Корзина с изменением количества и расчётом суммы.

## Важно
Это прототип витрины. Оплата, реальные заказы, доставка, остатки и юридические страницы не подключены. Цены примерные. Перед коммерческим запуском нужно проверить себестоимость, требования безопасности и применимые правила продажи товаров в Германии.
