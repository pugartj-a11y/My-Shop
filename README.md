# MEME BUDDIES — My Shop

Полноценный frontend-прототип интернет-магазина концептуального бренда 3D-брелков.

## Структура
- index.html — главная страница, каталог, FAQ, контакты и корзина.
- styles.css — адаптивный фирменный дизайн.
- app.js — каталог, поиск, фильтры и корзина с сохранением в localStorage.
- assets/meme-buddies-concept.jpg — сгенерированный визуальный концепт коллекции.
- assets/favicon.svg — иконка проекта.

## Запуск
Откройте index.html в браузере. Для локального сервера можно использовать команду python -m http.server 8000 из корня проекта и перейти на http://localhost:8000.

## GitHub Pages
Откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку /(root), затем нажмите Save.

## Возможности
- Адаптивная витрина для смартфонов и компьютеров.
- Шесть персонажей с демонстрационными ценами.
- Поиск по названию и описанию.
- Фильтры Common / Rare / Limited.
- Корзина с добавлением, удалением и изменением количества.
- Сохранение корзины в браузере через localStorage.
- FAQ и навигация по разделам.

## Перед настоящими продажами
Это frontend-прототип. Реальные заказы, платежи, управление остатками, доставка, e-mail-уведомления и юридические страницы не подключены. Цены примерные, а изображение — концепт оформления, не подтверждение готового товара. Перед коммерческим запуском в Германии проверьте применимые требования GPSR, Impressum, Datenschutz, Widerruf и VerpackG/LUCID. Если предприниматель несовершеннолетний, отдельно проверьте требования §112 BGB, согласие родителей и разрешение Familiengericht.
