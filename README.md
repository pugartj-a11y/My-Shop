# MEME BUDDIES — My Shop

Адаптивный frontend-прототип магазина коллекционных 3D-брелков.

## Что есть в проекте
- Адаптивная главная страница и мобильная навигация.
- Каталог из шести персонажей с отдельными SVG-иллюстрациями.
- Поиск и фильтры по редкости.
- Избранное и корзина с сохранением в браузере через localStorage.
- Расчёт суммы корзины в евро, FAQ и раздел о бренде.
- Страница 404, favicon, PWA manifest и robots.txt.

## Запуск локально
Открой index.html в браузере или запусти `python -m http.server 8000`, затем открой http://localhost:8000.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Важно
Это frontend-прототип, а не готовая платформа электронной коммерции. Корзина работает локально в браузере; backend, реальные заказы, платежи, остатки, доставка и e-mail-уведомления не подключены. Цены демонстрационные, а SVG-изображения — концептуальные иллюстрации, не подтверждение изготовленных или испытанных товаров.

Перед продажами в Германии проверь применимые требования, включая GPSR, Impressum, Datenschutz, Widerruf, VerpackG/LUCID и правила для товаров, которые могут считаться игрушками. Если основатель несовершеннолетний, заранее проверь требования к ведению бизнеса с участием родителей и Familiengericht.
